# springboot

第一层：Java 后端基础

优先掌握

- Java 面向对象、接口、继承、多态
- 集合框架：List、Map、Set
- 泛型、异常处理、注解、反射
- Lambda、Stream、Optional
- Maven、JDK、IDEA
- JDBC、MySQL、MyBatis

第二层：Web 基础

优先掌握

- HTTP 请求和响应
- GET、POST、PUT、DELETE
- JSON 数据格式
- RESTful API
- Cookie、Session、Token 的基本概念
- SQL、索引、事务

第三层：Spring Boot 后端框架

- Spring IoC、DI、Bean
- Spring MVC、Controller
- Service、DAO / Mapper
- MyBatis / MyBatis-Plus
- 参数校验、统一异常处理
- 事务、日志、配置文件
- Spring Security 或其他认证授权方案

第四层：Vue 3 前端

- HTML：页面结构
- CSS：页面样式
- JavaScript：编程逻辑
- ES6+：模块、箭头函数、Promise、async/await
- Vue 3：组件、响应式、生命周期、事件
- Vue Router：页面路由
- Pinia：状态管理
- Axios：调用后端 API



考虑到你还要兼顾公司工作，我建议先按每周 4～6 小时安排。如果实际每周只有 4 小时，可以延长计划，不必为了赶进度牺牲理解。

## 第 1 周

Java

补齐 Java 基础

集合、泛型、异常、注解、Lambda，重点看懂 Java 项目代码。

验收：能够独立写一个简单的用户管理类，并使用集合完成查询和过滤。

## 第 2 周

数据库

MySQL + MyBatis

建表、CRUD、JOIN、Mapper 接口、XML、参数绑定。

验收：不用复制完整模板，自己写出用户表的增删改查。

## 第 3 周

Spring

Spring Boot 入门

IoC、DI、Bean、自动配置、配置文件、Controller。

验收：启动一个 Spring Boot 项目，并提供两个可以正常访问的 HTTP 接口。

## 第 4 周

后端

完整的后端分层

Controller、Service、Mapper、事务、统一异常处理。

验收：完成一个连接 MySQL 的用户管理 REST API。

## 第 5 周

前端

HTML + CSS + JavaScript

表格、表单、事件、对象、数组、模块、异步请求。

验收：能看懂简单的 HTML 页面，并使用 JavaScript 操作表格数据。

## 第 6 周

Vue 3

Vue 3 基础

Composition API、响应式、组件、事件、路由、Axios。

验收：完成一个可以显示用户列表的 Vue 页面。

## 第 7 周

前后端联调

打通整个应用

Vue 调用 Spring Boot，实现查询、新增、修改、删除。

验收：前端提交表单，后端保存到 MySQL，再重新查询并展示。

## 第 8 周

项目实战

完成一个小型后台管理系统

添加分页、参数校验、统一异常处理、基础登录认证和部署配置。

验收：能够从启动后端、启动前端到完成一项业务操作，全流程独立运行。
